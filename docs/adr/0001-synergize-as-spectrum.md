# Synergize is a spectrum, not just collaboration

Originally, the **Synergize** step in the Surrender→Share framework was understood as collaboration — reach out to the existing builder, contribute features, or partner. In practice, when a user has no time, no team, or no fit for collaboration, the framework collapsed and skipped past synergize entirely.

We decided **Synergize** is a spectrum that includes: contributing to OSS, donating, amplifying, praying for the existing builder, and simply using and blessing what already exists. Choosing not to build because someone else is faithfully doing the work is itself a synergize action.

This preserves the 5-S alliteration of the framework (Surrender, Scour, Synergize, Sow, Share) while removing the binary trap. The rejected alternative — adding a 6th step like "Bless what exists" — was rejected because it bloats the framework and breaks memorability.

Hard to reverse because the framework's identity is tied to these five terms; future contributors will likely encounter the binary reading of synergize and try to "fix" it. This ADR exists so they understand the spectrum was the deliberate choice.
